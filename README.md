## Olá! 👋 Sou o João Vitor de Medeiros

Desenvolvedor Full-Stack | Automação, Dados & Legal Tech

Sou um desenvolvedor focado na criação de sistemas web completos, atualmente cursando Análise e Desenvolvimento de Sistemas (ADS) pela Cesar School. Minha trajetória tem um grande diferencial: trago a expertise da minha carreira jurídica como advogado especialista em Direito Contratual e análise de riscos. Hoje, aplico essa visão analítica na tecnologia, transformando regras de negócios complexas em sistemas escaláveis, automatizados e nativamente seguros, com forte foco em governança de dados e LGPD (Privacy by Design).

* 🔭 Em desenvolvimento: Construindo em equipe o Projeto Ponte Cultural, uma plataforma web de marketplace para conectar produtores culturais a empresas patrocinadoras.
* 🌱 Aprendendo: Aprofundando os estudos em Node.js, React, Express, Prisma, SQLite e PostgreSQL. Recentemente, comecei a aprender C também.
* 🏆 Conquista recente: 2º lugar no DemoDay da Residência Tecnológica do Porto Digital (2026), entre 60 equipes.
* ⚙️ Especialidades: Integração de APIs, engenharia de dados, automações em Python (RPA) e estruturação de banco de dados.
* ⚡ O que me destaca: Uno a lógica de programação com a visão de compliance. Consigo traduzir processos burocráticos e contratos complexos diretamente para o código, garantindo eficiência e segurança no tratamento de dados sensíveis no back-end.
